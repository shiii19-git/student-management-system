# Student Management System (C++)

Compact console project with 4 modules:
1. Add and update student records
2. Search and display student details
3. Enter marks and calculate grades (A-F)
4. Generate student result reports (individual and class)

Build: `g++ -std=c++11 student_system.cpp -o sms` then `./sms`

Data is saved in `students.txt`. A student passes if they score 40+ in every subject.
